# Traffic Complaint and Incident Management System

## About the Project
The **Traffic Complaint and Incident Management System** is a Java-based desktop application developed using Java AWT and MySQL. It provides a graphical interface for reporting and managing traffic-related complaints and incidents.

The system is designed to make traffic complaint records easier to maintain and manage.

## Features
- Report ID management
- Enter reporter name and contact number
- Add complaint or incident location
- Select complaint categories
- Enter vehicle registration number
- Add incident descriptions
- Track complaint status
- GUI buttons for Create, Read, Update, Delete and Clear operations

## Technologies Used
- Java
- Java AWT
- MySQL
- JDBC (Java Database Connectivity)
- IntelliJ IDEA

## Complaint Categories
- Illegal Parking
- Traffic Signal Violation
- Over Speeding
- Wrong Side Driving
- Road Accident
- Traffic Jam
- Road Blockage
- Other

## Requirements
- Java JDK
- MySQL Server
- MySQL Connector/J
- Java IDE (IntelliJ IDEA recommended)

## Database Setup
1. Open MySQL Workbench.
2. Create a database named `TrafficManagementDB`.
3. Import the provided `TrafficManagementDB.sql` file.
4. Ensure MySQL Server is running.
5. Configure your database connection credentials securely.

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Add the MySQL Connector/J library.
4. Configure your database credentials using environment variables.
5. Run the Java GUI main class.
